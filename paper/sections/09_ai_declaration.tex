\section*{Declaration of Generative AI Use}

Generative AI tools were used in this project, and every use is logged with its date, tool, task and validation in
\texttt{docs/AI\_USAGE.md} in the project repository.
Claude Code (Anthropic) and Codex (OpenAI) were used as programming assistants: to write the data loaders, the CWW
library, the experiment scripts, the tests, the word-meaning lab and the build scripts of this paper, each against a
written task description and reviewed in a pull request.
Claude Code also drafted the text of this paper from the analysis plans, the result files and the decision log, and
checked references against OpenAlex and the cited web pages.
Every number in the paper is generated from the result files by a script, and a test fails on any number typed by hand.
The LLMs studied in RQ2 (Section~\ref{sec:design-llm}) are research objects, not tools of authorship.
The authors defined the research questions and the analysis plans, reviewed every pull request and decision, and take
full responsibility for the content.
