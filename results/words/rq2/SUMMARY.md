## Deviations

- None from the frozen RQ2 analysis plan in the quantities estimated. Implementation choices (all set before the real-data run except the zero-IQR rule below):
- Valid answer = stored value present and in [0, 100] (strict parsing, D19); no further cleaning.
- Model-terms with < 30 valid answers are excluded (WP4 brief). For such a term the LLM IT2 is the envelope of the remaining models, the pooled-LLM IQR pools only eligible models, and that model's H2b share is taken over its eligible terms (denominator shown in the H2b table).
- Citizen resampling draws whole respondents, as in the RQ1 bootstrap, so cross-term dependence is kept; the six-group IT2 is re-derived in every replicate with the n >= 30 rule (group-term cells dropped over all replicates: 0).
- Independent streams: SeedSequence(seed).spawn(3) gives citizen, P1 and P2 generators; P1 and P2 share the citizen replicates.
- H2a uses the IT2 Jaccard of the plan (citizen IT2 vs LLM IT2); H2b uses a strict inequality (equal IQRs count as not narrower).
- Verdicts: "supported" only if the CI rule in the brief holds; otherwise "not supported" (exploratory, no multiplicity correction).
- Centroid shift: IT2 uses EKM centres (c_l + c_r) / 2; per model it is the T1 centroid minus the pooled citizen T1 centroid. IQR uses numpy linear quantiles of the raw values; width ratio = LLM IQR / citizen pooled IQR.
- Width ratio is undefined (NaN, no CI) for a term whose citizen IQR is 0 (About Even); H2b compares IQRs directly, so such a term is never counted as narrower and stays in the denominator. This rule was added after the first run on the real data stopped on a division by zero; it does not change any other number.
- A collapsed model set is a one-point spike on the 0.5 grid; it still enters the IT2 envelope, Jaccard and centroids. Its IQR is 0, so it counts as narrower in H2b unless the citizen IQR is also 0.
- Percentile CIs of discrete statistics (shares) and of collapsed sets can be degenerate (lo = hi).
